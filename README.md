# Which Model To Use

One prompt that adds a short "Which model to use" section to your CLAUDE.md, the file Claude reads every session, so work goes to the cheapest model that can do it properly.

**Who it is for:** Anyone using Claude Code who wants helper agents running on the right model.

**What you need:** Claude Code or Codex, and a CLAUDE.md file for Claude to add the section to.

## How to use it

Open `SETUP-PROMPT.md`, copy the prompt in it, and paste it into a new chat. Claude shows you the change before it saves it, and your existing rules stay exactly as they are.
